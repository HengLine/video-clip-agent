# NeoClip 控制台使用指南

> NeoClip 以「人机协同 / 深度参与」为核心，**控制台实时交互是主要使用方式**；REST 异步提交（`/api/v1/tasks`）仅为备用方案。

控制台是一个**交互式 REPL**（Read-Eval-Print Loop）：你输入自然语言指令，系统实时解析意图、评估风险、路由到对应智能体，高风险操作会停下来等你确认。整个过程在同一个会话里持续进行，系统会记住上下文。

---

## 1. 启动控制台

```bash
# 方式一：命令行入口（推荐，需先 pip install -e .）
pip install -e . --no-build-isolation -i https://pypi.tuna.tsinghua.edu.cn/simple
neoclip-cli

# 方式二：指定会话 ID（便于恢复/区分不同会话）
neoclip-cli --session my-vlog

# 方式三：模块方式（开发环境）
python -m neoclip.cli.main
```

> 若使用模块方式且未 `pip install -e`，需先 `export PYTHONPATH=src`（Linux/macOS）或 `set PYTHONPATH=src`（Windows）。

启动后界面：

```
NeoClip 交互控制台 — session: sess_1a2b3c4d
输入自然语言指令开始（help 查看命令，exit 退出）
neoclip>
```

`neoclip>` 是命令提示符，在它后面输入指令回车即可。

---

## 2. 内置命令

| 命令 | 别名 | 说明 |
| :-- | :-- | :-- |
| `help` | `帮助` | 显示帮助信息与示例 |
| `capabilities` | `能力` / `能做什么` / `功能` | 列出已注册的智能体能力 |
| `status` | `状态` | 查看系统运行状态 |
| `exit` | `quit` / `退出` | 退出控制台 |

> 退出也可直接按 `Ctrl+C`（发送中断）或 `Ctrl+D`（EOF，Linux/macOS）。

---

## 3. 三种交互模式

控制台支持三种交互模式，满足从一次性指令到多轮协作的创作过程。

### 3.1 一次性指令

直接输入一句完整指令，系统立即处理：

```
neoclip> 能做什么
4 个能力已注册：
  - timeline_planner
  - video_analyzer
  - segment_matcher
  - video_composer
```

### 3.2 澄清式对话

当指令**过短（单字）或未命中任何关键词**时，系统会反问，引导你补充细节：

```
neoclip> 剪
请详细描述您的需求，例如'把自我介绍放开头，活动放中间，风景放结尾'
neoclip> 把自我介绍这段剪到 10 秒
```

### 3.3 渐进式细化

系统按 `session_id` 记住上下文，支持代词指代与连续调整。上一轮的「这段」「它」能解析到具体对象：

```
neoclip> 做一个旅行 Vlog，风景放开头，美食放中间
[OK] Created timeline with 3 slot(s)
  Intent: plan_create

neoclip> 把第二段换成夜景素材
[OK] ...
  Intent: clip_replace
```

## 4. 风险确认（高风险操作必须先确认）

中枢对每个意图做风险评估，**高风险操作不会立即执行**，而是停下来等你确认：

| 风险 | 示例操作 | 策略 |
| :-- | :-- | :-- |
| 低 | 调音量、换转场、预览、查询进度 | 直接执行，可撤销 |
| 中 | 替换素材、裁剪片段、加滤镜 | 执行并高亮，可回退 |
| 高 | 创建/删除规划、最终渲染 | **必须先确认** |

高风险操作会弹出确认提示：

```
neoclip> 最终渲染
确认开始最终渲染？渲染开始后中途取消可能导致不完整输出。
确认执行? [y/N]
```

- 输入 `y` / `yes` / `确认` → 执行操作
- 输入 `n` / `no` / `取消` 或直接回车 → 取消操作

```
确认执行? [y/N] n
[OK] 已取消 state_render
  Intent: state_render
```

确认执行：

```
确认执行? [y/N] y
[OK] Video rendered to data/output\output.mp4
  Intent: state_render
  Data: {'output_path': 'data/output\\output.mp4', 'command': 'ffmpeg -i input.mp4 output.mp4'}
```

## 5. 会话管理

- **默认自动生成**会话 ID（`sess_xxxxxxxx`），同一进程内的对话共享上下文。
- 指定 `--session` 可让多次启动复用同一会话标识。
- 上下文（对话历史、代词指代、待确认操作）保存在内存中，进程退出即清空；持久化将在 V0.2 接入 SQLite。

## 7. 与 REST 异步的关系

| 方式 | 定位 | 特点 |
| :-- | :-- | :-- |
| 控制台（REPL） | **主要** | 实时交互、支持确认与澄清、上下文连续 |
| REST 异步（`/api/v1/tasks`） | 备用 | 提交任务取 `task_id`，轮询结果，适合脚本/服务集成 |

两者共用同一 `CentralHub`。REST 异步路径下，高风险操作同样会返回「待确认」状态而非直接执行——这是深度参与设计的一致体现。

---

## 8. 常见问题

| 问题 | 处理 |
| :-- | :-- |
| 提示 `No capability registered` | 未注册智能体；通过 `neoclip-cli` 入口启动会自动注册 4 个核心智能体 |
| 输入被反问「请详细描述」 | 指令过短或未命中关键词，补充更完整的描述即可 |
| 想跳过确认直接执行 | 当前设计不允许高风险操作跳过确认（人机协同约束） |
| 退出后能恢复上次对话吗 | V0.1 内存态暂不支持跨进程恢复，V0.2 接入 SQLite 后支持 |
