架构设计 · 星型中枢

所有指令到达中枢，意图识别 → 路由分发 → 智能体执行。线性链路作为标准工作流注册其中。

指令解析中枢

单一入口，统一处理用户自然语言指令。

  • 意图分类（规划 / 分析 / 匹配 / 合成）
  • 上下文消歧（代词、指代）
  • 风险评估（低 / 中 / 高 分级确认）
  • 能力路由（查注册表分发智能体）

能力注册 + 插件化

智能体宣告能力，中枢动态路由。从内部注册到对外插件 SDK，架构连贯演进。

  • 规划师 · 分析 · 匹配 · 合成
  • 线性链路作为默认工作流
  • V2.0 插件市场 + 沙箱安全
  • 即插即用，生态开放
上传 → 采样 → 中枢解析 → 规划提案 → 审核 → 分析 → 匹配 → 合成 人机协同

智能体协作

四个核心智能体共享全局状态，通过 LangGraph 编排，支持中断与恢复。

规划师 自然语言 → 时间线蓝图
视频分析 场景分割 + CLIP 语义标注
片段匹配 标签 → 向量 → 混合检索
视频合成 转场 · 音频 · GPU 渲染
人机协同审核： 规划、匹配、合成各阶段可中断、修改、确认，用户始终掌控。
